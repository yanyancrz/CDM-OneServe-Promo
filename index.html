Take OneServe With You

OneServe is used on your phone — install the app to your home screen to get started. Administrators use the administrative interface on a desktop or laptop.

Install on Android

  1. 1Open the official CDM OneServe application link using Google Chrome.
  2. 2Wait for the application to load completely.
  3. 3If an Install App or Add to Home Screen prompt appears, tap it.
  4. 4If no prompt appears, open Chrome's three-dot menu and look for Install app or Add to Home screen.
  5. 5Confirm the installation and wait for it to finish.
  6. 6Find the OneServe icon on your home screen or app list and open it.

Installation Troubleshooting

Why is the Install option missing?

The install option depends on your browser and the app's configuration. Open the official OneServe link in a supported, up-to-date browser and let the page finish loading. On iPhone/iPad use Safari's Share menu; on Android use Chrome's menu. If it still does not appear, contact the CDM OneServe administrator for help.

Why does "Add to Home Screen" not appear?

On iPhone/iPad the option is inside Safari's Share menu and the label can vary by iOS version. On Android it may be inside Chrome's menu as "Install app" or "Add to Home screen." Make sure you are using a supported browser and the latest iOS or Android version available for your device.

Can I use OneServe without installing it?

On mobile, OneServe is meant to be used as an installed app — install it to your device to get started. If you cannot install it, follow the steps above or contact the CDM OneServe administrator. (The administrative system is used in a browser on a desktop or laptop.)

Why is the app not opening correctly?

Try reloading the page, clearing your browser cache, or opening the official link again in a supported, up-to-date browser. Check that you have a stable internet connection.

What should I do if installation fails?

Restart your browser and try again. If the problem persists, use OneServe directly in the browser and continue to follow its supported workflow. Contact your campus administrator if you still cannot access the platform.

Installability depends on the OneServe application's HTTPS deployment, PWA manifest, service worker, and supported browser configuration. Installation happens from the actual OneServe application URL — this promotional site does not install OneServe.
